# Review Report — Security / Performance / Best Practice (2026-11-07)

## Verified solid (no action)
Auth: hashed session tokens, rotation on login, sliding+absolute expiry,
constant-time compares. CSRF: HMAC-tied double-submit. SQL: fully
parameterized everywhere — dynamic UPDATE SETs build column names from
fixed whitelists + $n placeholders (cms, packages, attendance, students),
no injection paths found. Academy isolation enforced in every query.
Errors mapped via toSafeResponse (no SQL leakage). Rate limiting is
DB-backed (email+IP windows). Admin routes consistently gated via
handleApiRequest (role+academy+CSRF).

## Fixed in this pass
1. Security headers added (next.config.ts): CSP incl. YouTube frame-src,
   X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy.
2. YouTube iframes → youtube-nocookie.com + loading="lazy" (landing +
   parent videos) — privacy + faster initial paint.

  gitignore it.
- MED gallery mediaKey (admin input, ≤500 chars) is rendered as <img src>

  Fix: validate https?:// at the API or render via next/image.
